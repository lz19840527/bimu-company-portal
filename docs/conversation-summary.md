# 彼慕智造公司门户：对话整理

整理日期：2026-10-22（Asia/Shanghai）。本文件是需求、决策和交付结果的整理稿，覆盖本对话自 2026-09-06 起的网站及视频工作，不是逐字聊天导出。登录账号、密码、访问令牌、内部工具日志和推理记录未收录。

## 最终目标与项目定位

以用户提供的《彼慕智造2026.pdf》及 BCDT、BCDC、BCV 产品资料为基础，建设江苏彼慕智造建筑科技有限公司门户，呈现工程技术服务、自研数字产品、真实工程业绩和合作咨询入口；同时制作公司宣传片与三款产品独立演示视频。

用户确认公司域名为 **bim-u.com**。配置页面规范地址与实际绑定域名是两项工作；最近一次发布记录未确认该域名已绑定。

## 需求演进与执行结果

### 1. 首版门户

初版采用 BIMU 标识、深青与浅绿、真实建筑影像，包含三款产品介绍、全过程技术服务、代表案例、宣传册下载及联系方式，适配手机布局。产品正式下载或访问地址未核准时，以产品介绍和咨询入口承接需求。

首版本地交付后，托管上传一度超时。后续通过恢复工作完成托管发布，不能把中间失败记录当作当前仍未发布。

### 2. 公司宣传片与多轮修订

按用户要求先制作 120 秒、1080p 公司片，沿用既有女声，加入配乐及中文字幕。随后逐步完成：

- 去除重复背景，加入三款产品真实模块界面，原女声提速 10%。
- BCV 改用 Android 模拟器中的移动端界面，展示图层、属性、剖切与测量。
- BCDC 改用用户指定的新平台地址采集真实项目、料单与审批界面；登录信息不进入本归档。
- 延长为 180 秒，增加 BCDT 11 个一级模块、BCV 点到线和点到面测量，以及全部 43 张业绩图片的快速遍历。
- 以宣传册第二页图片和文字设计 20 秒片头，扩展为 200 秒。
- 增加三产品概述与业务关系，优化功能解说和过渡；右侧网格替换为数字建筑逐层生成动画，调整成熟女声、语速及业绩段音乐强度。
- 最后生成钢琴配乐版，解说期间配乐保持播放，不按人声自动压低。音乐来源与当时页面标注保存在制作说明中。

这些是历史制作版本，不代表网站同时播放全部版本。网站收录的是另行压缩和混音的网页适配版；公司片网页版本采用原创 Precision Lines 配乐。

### 3. 三款产品独立演示

用户最初建议每款 120 秒，并允许为完整功能自行调整时长。最终本地文件为：

| 产品 | 时长 | 主要展示范围 |
| --- | ---: | --- |
| BCDT | 230 秒 | 项目检查、构件库与身份、材料专业设计、加工资料与受控交付；11 个一级模块 |
| BCDC | 160 秒 | 项目空间、料单、复核与版本、材料、文件、知识、项目信息、邮件和助手入口 |
| BCV | 180 秒 | 移动端模型查看、图层、属性、剖切、两点/边长/点到线/点到面/面积测量等 |

三个视频沿用公司片女声，使用各自原创配乐、中文字幕。历史制作报告记录了完整解码、字幕时序、时长和音频检查。展示功能入口与完整业务验收是不同结论，不能由演示片推导所有命令或交易链路均已验收。

### 4. 门户规划与第一期实施

2026-10-03，基于公司服务及产品当时已完成与未完成的状态形成[门户规划](portal-plan-2026-10-03.md)，用户随后要求实施。

规划将门户定位为“工程技术服务＋数字产品＋客户服务入口”，主导航包括首页、解决方案、数字产品、工程实践、资源中心、关于彼慕，并保留项目咨询。

第一期实现 14 个主要中文页面，整合公司片和三款产品片。中途因额度暂停并停止临时预览与上传；用户明确恢复后继续，2026-10-11 完成私有站点第一版发布。

## 产品表达与事实边界

三产品以 **BCDT 设计与加工资料 → BCDC 项目数据组织 → BCV 模型查看与现场核对** 解释业务关系。该关系不等同于已具备统一账号、自动同步或完整闭环。

- **BCDT**：强调有依据的设计、材料专业模块、加工资料和受控交付。候选成果、正式生产成果及审批条件不得混写。
- **BCDC**：已展示材料、文件、知识和项目信息相关能力；模型、现场、协同及独立 AI 中心按当时证据保留规划边界。已有助手侧栏不等同于独立 AI 中心完成。
- **BCV**：按已有证据保留内测范围，模型显示网格测量存在精度和适用条件，不把未核准调试包当正式公开安装包。
- AI 辅助、自动建模、数字孪生和物联网等按真实阶段说明，不将研发方向包装为已普遍可用功能。

这些产品状态源自当时核对的资料，本次 Git 归档没有重新验收三款产品的最新版本。
